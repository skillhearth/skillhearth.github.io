Small agent skills that stay honest about your facts.

An agent skill is a folder with a SKILL.md file and a few reference files. Drop it into your AI agent's skills location and it gives the agent a clear, repeatable procedure. Ours never invent experience, numbers or results for you.

Job Application Tailor

US$12

Give it your resume and one job posting. It builds the application materials from what you have actually done, and nothing else.

  • Screens the posting for common scam indicators first (for example, requests for money or bank/ID details) and reports them as things to verify, not as a verdict. The list of signals is not exhaustive.
  • Extracts requirements and keywords from the posting.
  • Builds a requirement-to-evidence fit table (Strong / Partial / Gap / Unknown) with honest gaps.
  • Suggests resume edits from your real experience only; drafts a cover letter and interview-answer skeletons.

It will not write experience you do not have, does not promise replies, interviews or jobs, and is not legal, immigration or career advice. Personal-use license.

Debt Payoff & Budget Planner

US$9
Educational use only. Not financial, tax or legal advice. Simplified interest model: annual rate ÷ 12, no fees. Recommends no financial product or provider.

You enter income, expenses and debts; it computes your monthly leftover and compares the avalanche and snowball methods using only your numbers, with the arithmetic shown.

  • Budget snapshot and debt table with first-month interest.
  • Flags any debt whose minimum does not cover its interest in the model.
  • Minimum-only baseline vs. avalanche vs. snowball: order, balances, months to zero, total interest.
  • If there is no leftover, it shows the shortfall instead of a misleading projection.

Personal-use license, educational only. It does not promise any result.

What's inside

  • SKILL.md – the procedure the agent follows (plain text).
  • references/ – short reference files and a fictional worked example.
  • README.md and a license file.

Text only: no code to run, no executables, no network access required.

How to use

  1. Download and unzip. You get one folder containing SKILL.md.
  2. Put that folder in your agent's skills folder (where your agent looks for skills).
  3. Start a session and give the agent your input (for example, your resume bullets), as described in the skill's README.

For the free skill, this command was observed working in our own test:

npx skills add skillhearth/resume-bullet-rewriter

Observed in our own test only; we do not know how it behaves in your setup.

Honest limits

  • Tested on: our own fictional test cases (3 per skill), not on any specific platform. The test agent was the same AI system that wrote the skills, so this is weak evidence. We make no compatibility claims beyond this: the skills follow the SKILL.md folder format.
  • No outcome promises. The resume skill does not promise interviews or jobs; the application skill does not promise replies.
  • The skills work only from what you give them. They do not verify your claims, and they do not state country-specific rules.
  • The scam-signal list in Job Application Tailor is not exhaustive. Always verify an employer yourself.
  • The debt planner is educational only, uses a simplified model (annual rate ÷ 12, no fees, fixed rates, constant income and expenses) and real loans can differ.
